# Лабораторна: токенізація та позиційне кодування

Навчальна лабораторна у форматі Python/VS Code notebook. Вона послідовно
розглядає word-level токенізацію, OOV, символьні n-грами, BPE, синусоїдальне
та навчене позиційне кодування.

Відкрийте [`tokenizer.py`](tokenizer.py) у редакторі з підтримкою Python cells
і виконуйте секції `# %%` по черзі, замінюючи `...` власною реалізацією.

Щоб згенерувати звичайний Jupyter notebook:

```bash
make notebook
```

Команда створить `tokenizer.ipynb` без додаткових Python-залежностей.
