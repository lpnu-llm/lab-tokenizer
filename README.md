# Лабораторна: токенізація

Лабораторна послідовно розглядає word-level токенізацію, OOV, символьні
n-грами, BPE, WordPiece та порівняння токенізаторів на багатомовному корпусі
FLORES.

## Файл для студентів

Відкрийте [`tokenizer.ipynb`](tokenizer.ipynb) у Jupyter або VS Code та
виконуйте комірки по черзі, реалізуючи позначені завдання.

Встановити uv: 

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```


Перед початком встановіть залежності:

```bash
uv sync
```

Для повторної генерації notebook після змін у вихідному файлі:

```bash
make notebook
```

Команда оновить студентський `tokenizer.ipynb`.
